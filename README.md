# Админ в коробке — обновления

Здесь лежат только готовые сборки программы «Админ в коробке» для автообновления серверов клиентов.

- `version.txt` — последняя версия для каналов `test` и `stable` (подписана ключом администратора).
- `releases/<версия>/Admin-v-korobke.exe` — сама программа.

Серверы ставят только сборки с правильной подписью. Закрытого ключа здесь нет.
